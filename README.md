### 📂 Selected Work

- **Secure Cold-Chain Monitor** *(simulated)* `2026`  
  ESP32-S3 simulation that tracks temperature, shock, light, and door events for cold-chain logistics. Telemetry is published over MQTT. Every record is hash-chained (SHA-256) and HMAC-signed so any tampering is immediately detectable. Includes a Python verifier, live dashboard, deliberate forgery script, and optional LLM-assisted incident reporting.  
  *Stack:* C++ (Arduino / PlatformIO) · Python · MQTT · Wokwi  
  [🔗 Repository](https://github.com/Damiiner/secure-cold-chain-monitor)

- **ShopFlow** `2025`  
  Full-stack e-commerce platform. Sellers manage product listings while customers browse and purchase. Front end and back end live in the same repository with a documented Postman collection for the API.  
  [🔗 Repository](https://github.com/Damiiner/ShopFlow)

- **LocalFix** `2025` *(Group Project)*  
  Community platform matching people needing help with nearby helpers. Features a task board with category filters, status tracking, and an interactive Leaflet map.  
  *Contribution:* Complete front end (React, Vite, React Router, Leaflet) and project report. Runs independently with sample data.  
  [🔗 Repository](https://github.com/Damiiner/LocalFix) · [📄 Project Report (PDF)](https://github.com/Damiiner/LocalFix/blob/main/docs/LocalFix-report.pdf)

- **QueueLess** `2026` *(In Progress)*  
  Native Android application replacing physical queues at university administrative offices with digital tickets. Provides live positioning, wait-time estimates, turn notifications, and a staff dashboard.  
  [🔗 Repository](https://github.com/Damiiner/QueueLess)
